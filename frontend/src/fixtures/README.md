# Frontend evidence fixtures

These are small, selected records from the locally verified
`jezero-evidence-e4de0e69b0db0fd4` snapshot. They are not a complete mission
catalogue and are not synthetic positions.

The fixture uses the repository wire convention
`MARS_2000_PLANETOCENTRIC_EAST_360_V1`, not default Earth GeoJSON semantics.
It preserves the source URLs, source snapshot version and limitations. In
particular, NASA WMTS ↔ wire ↔ DEM alignment is not validated; displayed
positions provide selected demo visual context, not independently registered
terrain or astronaut-safety evidence.

Do not add data without its source URL, acquisition/ingestion information when
known, coordinate convention, and limitations.
